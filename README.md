# ResQNet – AI Powered Offline Disaster Mesh

ResQNet is an Android-based emergency communication system designed to work without internet connectivity during disaster situations.

## Features
- Bluetooth-based mesh communication
- Multi-hop message forwarding
- Emergency SOS alerts
- Real-time GPS location tracking
- Nearby device discovery
- Priority-based message handling

## Technologies Used
- Kotlin / Java
- Android Studio
- Bluetooth API
- WiFi Direct
- SQLite
- GPS (FusedLocationProviderClient)

## How it Works
The system creates a peer-to-peer mesh network where devices communicate directly using Bluetooth. Messages are forwarded across devices (multi-hop) until they reach the destination.

## Use Case
Useful in disaster situations where internet and mobile networks are unavailable.
